Movie Review Web App | Django, Python, HTML, API
• Built a full-stack Django application with user authentication and CRUD functionality.
• Implemented form handling using django-crispy-forms and Bootstrap.

What this website can do - this is a personal movie review site. 
    - Add a movie - add a review, comments, a file and tags for the said movie.
    - This is all connected to a MYSQL database.
    - You can also search more details for a Movie by click on the entry you added, it will take you a detail page where you can click on a 'get more details' button.
    - That will take you to a page with more details like - Release year, IMDB Rating, Director and Cast Info ( with their individual wikipedia page linked ), Awards won and Plot summary.
